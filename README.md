# Sistema Integrado de Orientación Escolar y Gestión de Horarios

Sistema para la gestión de horarios, mapas interactivos SVG y avisos en tiempo real para la comunidad educativa.

## Estructura del Repositorio

* `/app`: Código fuente de la aplicación móvil Android en Java.
* `/database`: Scripts de MariaDB (.sql) y modelos de datos.
* `/design`: Archivo del plano vectorial SVG de Inkscape, recursos de branding e íconos.
* `/docs`: Informe técnico de titulación, bitácoras de gestión y manuales de usuario.
* `/web`: Landing page oficial para promoción y descarga de la aplicación.
